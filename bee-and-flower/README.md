# ハチさんを おはなまで！

4〜6歳の子どもが、大きなボタンをタップしてハチをお花まで動かす、無料のプログラミング体験ゲームです。「命令をならべる → GOで動かす → 間違えたら直す」を、約10分の授業で体験できます。

ゲーム本体は **`index.html` 1ファイル**です。HTML・CSS・JavaScriptとイラスト用のインラインSVGを含み、外部ライブラリ、画像のダウンロード、サーバー、ログインは必要ありません。個人情報の取得やプレイ記録の保存は行いません。

Web公開先：**https://atsuhi.ro/apps/baby-programming/bee-and-flower/**。`main`の更新後、テストに成功するとGitHub Actionsから個人サイトへ自動反映します。[リポジトリ全体の公開設定](../README.md#自動公開)を参照してください。

タイトル・説明文・favicon・OGPの設定は `index.html` に直接記載しています。画像を差し替える場合は `favicon.ico`・`image.png` を更新し、OGP画像のサイズを変えた場合はHTML内の `og:image:width`・`og:image:height` も更新してください。

## 起動方法（Windows 8）

1. このリポジトリをZIPで入手して展開し、`bee-and-flower` フォルダーを開くか、配布された `index.html` をPCのフォルダーに保存します。準備後はインターネット接続不要です。
2. **Chrome 109 または Firefox 115 ESR**を起動用のブラウザーとして用意します。本ゲームはこれらで動作するよう設計していますが、Windows 8実機では未検証です。
3. `index.html` をダブルクリックします。別のブラウザーで開いた場合は、ファイルを右クリックして「プログラムから開く」からChromeまたはFirefoxを選んでください。ZIPの中から直接開かず、先に展開してください。
4. ブラウザーのアドレスが `file:///.../index.html` で始まり、2つのモード選択ボタンが表示されれば準備完了です。
5. 「かんたん」または「チャレンジ」をタップして遊びます。

授業前に先生が各PCで開いておけます。画面が小さく感じる場合はブラウザーの表示倍率を100%に戻してください。PC側の表示倍率も含めた1024×768での実機確認は、授業前に行ってください。

ゲーム用に必要な配布ファイルは `index.html` だけです。faviconも使う場合は、同じフォルダーに `favicon.ico` を保存してください。OGPの設定はオフラインでのゲーム動作に影響しません。

## 遊び方

1. ハチの向きとお花の場所を見ます。
2. 大きな命令ボタンをタップし、命令を順番にならべます。
3. 「GO」をタップすると、ハチが最初の位置から命令を1つずつ実行します。実行中の命令が強調表示されます。
4. **最後の命令が終わった場所がお花なら成功**です。途中でお花を通り過ぎてしまうと成功にはなりません。
5. 成功したら同じ課題をもう一度遊ぶか、次の課題へ進めます。最後の課題まで遊んだ後も繰り返せます。

「前進」はハチが向いている方向へ1マス進みます。「左」「右」はその場で90度向きを変える命令で、回転だけではマスを移動しません。

命令は最大12個です。命令一覧の消したい命令をタップすると、その1個を削除できます。最後の命令だけを取り消すボタンもあります。「やりなおす」は命令をすべて消して、ハチを最初の位置に戻します。失敗後は命令が残るため、間違えた部分を直して再びGOを押せます。

実行中は命令の追加・削除やGOの連打を受け付けません。キーボード入力やドラッグ操作は使わず、タッチでもマウスのクリックでも遊べます。音がなくても操作や結果を理解できる構成です。

## 年齢別モード

| モード | 主な対象 | 内容 |
| --- | --- | --- |
| かんたん | 4〜5歳・初めて遊ぶ子 | 前進だけを使う直線コース。1マス、2マス、3マス、4マスの4課題で段階的に練習します。 |
| チャレンジ | 5〜6歳・前進に慣れた子 | 前進と左右への90度回転を使う4課題。簡単な課題から始め、曲がるコースで命令の順番を体験します。 |

どちらも障害物や条件分岐はありません。年齢は目安です。初めて遊ぶ子はかんたんモードから始めてください。

## オフライン動作の確認方法

授業で使うPCごとに、次を確認してください。

1. `index.html` をPC内に保存し、ChromeまたはFirefoxで開きます。
2. Wi-Fiをオフにし、有線LANを使っている場合はケーブルを外します。
3. ブラウザーを閉じ、保存した `index.html` をもう一度開きます。
4. 両方のモードで命令を追加し、GO・成功・失敗・やりなおすを試します。
5. ブラウザーを更新し、モード選択画面から再び正常に遊べることを確認します。

ゲームは通信機能、外部フォント、CDN、APIを利用しません。インターネットを切った状態で、ファイルを開き直して遊べることを確認すると、授業時と同じ条件を確かめられます。

## 対応環境と確認の限界

1024×768の画面とタッチ操作を前提に、64px以上のタップ領域、軽量なアニメーション、古いブラウザーを考慮したJavaScriptで実装しています。イラストはSVGで描き、絵文字の表示に依存しません。

**Windows 8実機での動作保証はしていません。** Chrome 109・Firefox 115 ESRの実際の組み合わせ、タッチドライバー、複数の指による操作、OSの表示倍率、低スペックPCでのアニメーション速度は未検証です。ブラウザーでの確認と、Windows 8実機での確認は区別してください。

検証用ブラウザーツールは `file://` を開けないため、実際の画面操作はローカルHTTPで確認しました。HTMLファイルのダブルクリック起動とネットワークを切った状態での再起動は未検証です。外部依存・通信処理がないことは自動テストとソースで確認しています。対象PCで上記のオフライン確認手順を実施してください。

授業前に対象PCで、ボタンの反応・画面の収まり・移動の見やすさと、上記のオフライン動作を確認してください。

## 開発時の確認

Node.jsがある開発環境では、外部パッケージを追加せずに次の確認を実行できます。ゲームを遊ぶPCにNode.jsは不要です。

```text
node --test
```

変更時はこの確認に加え、ブラウザーで `index.html` を直接開き、両モード・命令の編集・再挑戦・タッチ入力・1024×768表示・オフライン起動を確認してください。
