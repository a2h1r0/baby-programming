# ハチさんを おはなまで！

4〜6歳の子どもが、大きなボタンをタップしてハチをお花まで動かす、無料のプログラミング体験ゲームです。「命令をならべる → GOで動かす → 間違えたら直す」を、約10分の授業で体験できます。

ゲーム本体は **`index.html` 1ファイル**です。HTML・CSS・JavaScriptとイラスト用のインラインSVGを含み、外部ライブラリ、画像のダウンロード、サーバー、ログインは必要ありません。個人情報の取得やプレイ記録の保存は行いません。

Web公開先：**https://atsuhi.ro/apps/baby-programming/**。`main`の更新後、テストに成功するとGitHub Actionsから個人サイトへ自動反映します。[公開・同期の仕組みと確認方法](docs/publishing.md)を参照してください。

## 起動方法（Windows 8）

1. このリポジトリをZIPで入手して展開するか、配布された `index.html` をPCのフォルダーに保存します。準備後はインターネット接続不要です。
2. **Chrome 109 または Firefox 115 ESR**を起動用のブラウザーとして用意します。本ゲームはこれらで動作するよう設計していますが、Windows 8実機では未検証です。
3. `index.html` をダブルクリックします。別のブラウザーで開いた場合は、ファイルを右クリックして「プログラムから開く」からChromeまたはFirefoxを選んでください。ZIPの中から直接開かず、先に展開してください。
4. ブラウザーのアドレスが `file:///.../index.html` で始まり、「遊び方」のダイアログが表示されれば準備完了です。大人が説明を読み、「遊びを始める」を押します。
5. レベル1が開いたら、前進の矢印を1回タップし、「GO」をタップして遊び始めます。

授業前に先生が各PCで開いておけます。画面が小さく感じる場合はブラウザーの表示倍率を100%に戻してください。PC側の表示倍率も含めた1024×768での実機確認は、授業前に行ってください。

ゲーム用に必要な配布ファイルは `index.html` だけです。説明資料も使う場合は、このREADMEと `docs` フォルダーを一緒に保存してください。

## 遊び方

アクセス時には、漢字を使った遊び方の説明が表示されます。「遊びを始める」を押すまでゲームは操作できません。再読み込みすると説明を再表示しますが、レベル移動や再挑戦のたびには表示しません。

1. ハチの向きとお花の場所を見ます。
2. 大きな命令ボタンをタップし、命令を順番にならべます。
3. 「GO」をタップすると、ハチが最初の位置から命令を1つずつ実行します。実行中の命令が強調表示されます。
4. **最後の命令が終わった場所がお花なら成功**です。途中でお花を通り過ぎてしまうと成功にはなりません。
5. 成功したら「つぎへ」で次のレベルへ進めます。レベル数とプレイ回数に上限はありません。

「前進」はハチが向いている方向へ1マス進みます。「左」「右」はその場で90度向きを変える命令で、回転だけではマスを移動しません。

命令は最大12個です。命令一覧の消したい命令をタップすると、その1個を削除できます。最後の命令だけを取り消すボタンもあります。やりなおすボタンは命令をすべて消して、ハチを最初の位置に戻します。失敗するとダイアログに「もういっかい」ボタンを表示します。押すと矢印がすべて消え、ハチがスタートに戻るので、命令を最初から並べて再挑戦できます。同じレベルで再挑戦すると、ハチ・お花・岩の配置は変わりません。

画面の文字はレベル表示、変化する案内、成功表示などに絞り、命令や操作は大きなアイコンとGOで示しています。

実行中は命令の追加・削除やGOの連打を受け付けません。キーボード入力やドラッグ操作は使わず、タッチでもマウスのクリックでも遊べます。音がなくても操作や結果を理解できる構成です。

## レベルと難しさ

モード選択はなく、レベル1から始まります。最初は5レベルごとに新しい要素を加え、少しずつ練習できます。

| レベル | 内容 | 体験すること |
| --- | --- | --- |
| 1〜5 | 前進だけ。お花までの距離は順に1・2・2・3・4マス。 | 矢印と移動の関係、命令の数。 |
| 6〜10 | 左右への回転が加わる。 | ハチの向きと命令の順番。 |
| 11〜15 | 進路をふさぐ岩が現れる。 | 障害物を避ける経路。 |
| 16〜20 | 岩を避ける道が長くなる。 | 複数の命令を組み合わせること。 |
| 21〜25 | 曲がる回数が増える。 | 前進と回転の組み合わせ。 |
| 26〜30 | 曲がる道の案内を一部だけ表示する。 | 道の続きを自分で考えること。 |
| 31〜 | 道の案内なしで、配置を変えながらレベルが続く。 | 自分で経路を考えて試すこと。 |

盤面は5×5マス、命令は最大12個を保ちます。幼児が操作できる範囲を保つため、後半は11〜12命令で解ける難しさを基本に、道の向きや岩の配置を変えて続けます。レベル数・プレイ回数には上限を設けません。進み具合は保存せず、ブラウザーを更新するとレベル1から始まります。

## オフライン動作の確認方法

授業で使うPCごとに、次を確認してください。

1. `index.html` をPC内に保存し、ChromeまたはFirefoxで開きます。
2. Wi-Fiをオフにし、有線LANを使っている場合はケーブルを外します。
3. ブラウザーを閉じ、保存した `index.html` をもう一度開きます。
4. レベルを進めながら命令を追加し、GO・成功・失敗・やりなおすを試します。
5. ブラウザーを更新し、レベル1から再び正常に遊べることを確認します。

ゲームは通信機能、外部フォント、CDN、APIを利用しません。インターネットを切った状態で、ファイルを開き直して遊べることを確認すると、授業時と同じ条件を確かめられます。

## 対応環境と確認の限界

1024×768の画面とタッチ操作を前提に、64px以上のタップ領域、軽量なアニメーション、古いブラウザーを考慮したJavaScriptで実装しています。イラストはSVGで描き、絵文字の表示に依存しません。

**Windows 8実機での動作保証はしていません。** Chrome 109・Firefox 115 ESRの実際の組み合わせ、タッチドライバー、複数の指による操作、OSの表示倍率、低スペックPCでのアニメーション速度は未検証です。現在の開発環境で確認した結果は[動作検証記録](docs/testing.md)に記載しています。ブラウザーでの確認と、Windows 8実機での確認は区別してください。

検証用ブラウザーツールは `file://` を開けないため、実際の画面操作はローカルHTTPで確認しました。HTMLファイルのダブルクリック起動とネットワークを切った状態での再起動は未検証です。外部依存・通信処理がないことは自動テストとソースで確認しています。対象PCで上記のオフライン確認手順を実施してください。

授業前に対象PCで[チェックリスト](docs/touch-checklist.md)を実施し、ボタンの反応・画面の収まり・移動の見やすさを確認してください。

## 開発時の確認

Node.jsがある開発環境では、外部パッケージを追加せずに次の確認を実行できます。ゲームを遊ぶPCにNode.jsは不要です。

```text
node --test
```

変更時はこの確認に加え、ブラウザーで `index.html` を直接開き、レベルの進行・命令の編集・再挑戦・岩との衝突・タッチ入力・1024×768表示・オフライン起動を確認してください。検証条件と結果は `docs/testing.md` に残します。
