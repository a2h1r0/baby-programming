# 先生向け：10分間授業ガイド

## 授業のねらい

子どもが「自分でならべた命令どおりにハチが動いた」と感じることを優先します。全課題を終える必要はありません。1回の成功と、間違えた命令を直す経験ができれば十分です。

文字を読ませたり、回数を正解するまで答えさせたりする必要はありません。指差しや短い声かけで進めます。操作はすべてタップででき、音がなくても遊べます。

## 授業前の準備

1. 各PCに `index.html` を保存し、Chrome 109またはFirefox 115 ESRで開きます。ファイルの入手後はインターネット不要です。
2. インターネットを切った状態でファイルを開き直し、遊べることを確認します。
3. [タッチ操作・授業前チェックリスト](touch-checklist.md)を、実際に使うPCで実施します。Windows 8実機での動作は未検証なので、授業前確認を省略しないでください。
4. ブラウザーの表示倍率を100%にし、ボタンやGOが見えることを確認します。
5. 各PCは最初のモード選択画面にしておきます。必要なら先生が先にかんたんモードを選んでおきます。

前回の命令や進み具合は保存されません。ブラウザーを更新すればモード選択画面から始められます。

## 進行の目安

| 時間 | 先生の進め方 | 子どもの体験 |
| --- | --- | --- |
| 0〜2分 | ハチとお花を指差す。前進を1回タップし、命令一覧を見せてからGOを押す。 | ボタン、命令、ハチの移動がつながることを見る。 |
| 2〜7分 | かんたんモードで1〜2マスの課題を繰り返す。慣れた子は3〜4マスへ。 | 自分で命令をならべて実行し、成功する。 |
| 7〜9分 | 前進に慣れた子はチャレンジモードへ。ゆっくり取り組む子は同じ課題をもう一度遊ぶ。 | 回転を試す、または前進を自分の力でできるようにする。 |
| 9〜10分 | できた操作を一緒に振り返る。 | 「自分で動かした」「直してできた」と話す、または指差す。 |

## 最初の説明例

ハチとお花を指差しながら、次のくらい短く伝えます。

> 「ハチさんを、おはなまで つれていこう。このボタンで、ひとつ すすむよ。ならべたら、GO！」

命令ボタンを押しても、すぐにはハチが動かないことを実演してください。命令一覧を指差してからGOを押し、「ならべてから動かす」という順番を見せます。

## 慣れてきた子への説明

チャレンジモードでは、最初に回転だけを実演します。ハチの顔の向きに注目させます。

> 「くるっ、と むきを かえるよ。まだ すすまないよ。つぎに、すすむボタン！」

「前進」は画面の上へ進むという意味ではなく、ハチの顔が向いている方向へ1マス進みます。回転はその場で90度向きを変えます。先生がハチになって体の向きを変えて見せると、言葉を増やさずに伝えられます。

## 間違えたときの声かけ

- 命令が多すぎた：「どれを ひとつ けしてみようか？」命令一覧の1個をタップして削除できます。
- 順番を間違えた：「ここまで よかったね。つぎは どうしよう？」失敗後の命令が残るので、変更してGOを押せます。
- 全部やり直したい：「もういちど はじめから やってみよう。」やりなおすボタンで命令が消え、最初の位置に戻ります。
- 実行中に何度も押す：「うごいている あいだは、みてみよう。」実行中は追加や重複実行を受け付けません。
- お花を通り過ぎた：「おはなの ところで とまれるかな？」最後の命令が終わった場所がお花なら成功です。

GOを押すたびに、ハチは課題の最初の位置から同じ命令列を実行します。直した結果を、前回と比べられます。最後の命令を取り消すボタンや、命令を1個ずつ消す操作も使えます。

## 終わりの振り返り

「どのボタンで動いた？」「どうしたらお花に着いた？」を1つだけ聞きます。答えを文章で言えなくても、命令ボタンを指差したり、ハチの動きをまねしたりすれば十分です。

成功した課題をもう一度遊ぶのもよい終わり方です。速さや課題数を競わせず、その子が自分で選んだ命令と結果を結びつけられたことを認めます。
